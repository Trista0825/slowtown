# 🏡 慢慢小鎮 Slowtown

> 慢慢來，比較快。

一款可愛文青風的小動物建設模擬遊戲。結合**開心農場**的種田樂趣、**生產線**的工坊經營、**商業**的訂單與小舖，還有**金融**的銀行與股市，讓你一天一天、慢慢把小鎮經營起來。

純前端（HTML + CSS + JavaScript），不需要伺服器、不需要安裝任何東西。可以放上 GitHub Pages，用手機或平板直接玩，也能「加到主畫面」當作 App 離線遊玩。

---

## 🚀 部署到 GitHub Pages（約 3 分鐘）

### 方法 A：用網頁上傳（不需要會 git）
1. 登入 GitHub，按右上角「＋」→ **New repository**。
2. Repository name 輸入 `slowtown`（或任何名字），選 **Public**，按 **Create repository**。
3. 在新的 repo 頁面點 **uploading an existing file**。
4. 把這個資料夾**裡面的所有檔案與資料夾**（`index.html`、`css/`、`js/`、`icons/`、`sw.js`、`manifest.webmanifest`、`.nojekyll`…）一起拖進去，按 **Commit changes**。
   - ⚠️ 要上傳的是「資料夾裡的內容」，不是外層資料夾本身，`index.html` 必須在 repo 的最上層。
5. 進入 repo 的 **Settings → Pages**。
6. 在 **Build and deployment** 的 Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾選 **/ (root)**，按 **Save**。
7. 等 1～2 分鐘，頁面上方會出現網址：
   `https://你的帳號.github.io/slowtown/`

### 方法 B：用 git 指令
```bash
cd slowtown
git init
git add .
git commit -m "慢慢小鎮 v1.0"
git branch -M main
git remote add origin https://github.com/你的帳號/slowtown.git
git push -u origin main
```
然後一樣到 **Settings → Pages** 開啟（步驟 5～7）。

## 📱 在手機 / 平板上玩

| 裝置 | 步驟 |
|---|---|
| iPhone / iPad | 用 **Safari** 開網址 → 點「分享」按鈕 →「加入主畫面」 |
| Android | 用 **Chrome** 開網址 → 右上角「⋮」→「安裝應用程式」或「加到主畫面」 |

加到主畫面後會以全螢幕開啟，就像一般 App，第一次載入後也能離線玩。

**存檔**：自動存在該裝置的瀏覽器裡。想換手機時，到「日記 → 設定 → 匯出存檔」複製代碼，再到新裝置「匯入存檔」。

## 🎮 遊戲內容

### 主角
12 種小動物可選（兔子、小熊、貓咪、狐狸、小狗、企鵝、熊貓、無尾熊、倉鼠、青蛙、小老鼠、小老虎），加上 8 種圍巾顏色，隨時可以換造型。

### 🌾 農場
- 12 種作物，每種有成長時間與**當季加成**（當季快 25%）
- 點作物**澆水**可加速 20%，還有機會多收成
- 一鍵全部收成、一鍵全部播種

### 🏭 生產線
- 4 種畜牧（雞舍、乳牛、蜂箱、綿羊）＋ 8 座工坊（磨坊、麵包坊、牛奶工坊、茶屋、果醬小屋、花草店、織布工房、森林食堂）
- 26 種配方，多層加工鏈（小麥 → 麵粉 → 麵包 → 三明治）
- 生產排程、建築升級（Lv.1～3：排程變多、速度變快）

### 🛒 商業
- **居民訂單**：10 位動物居民會下訂單，交貨換金幣與經驗，還會累積**友情**（每顆心送一封信 + 四葉草）
- **市場**：價格會因供需與新聞波動，一次賣太多會跌價
- **文青小舖**：把商品上架，觀光客會自動來買（離線也會繼續營業）
- **熱氣球商隊**：大筆訂單，可分批交貨，報酬豐厚
- **繁榮度**：擺裝飾、蓋建築會讓客人變多

### 🏦 金融
- **企鵝銀行**：活存（每小時複利）、4 種定存方案、小額貸款
- **狐狸證券**：6 家小鎮上市公司，股價每 30 秒跳動，有財經新聞事件、股利、走勢圖
- **資產頁**：總資產、資產配置、成長曲線、經營紀錄

### 🌸 長期經營設計
- **季節循環**：一季＝現實一天，四季各有祭典（指定商品訂單 +30%、售價 +20%），畫面與飄落粒子會跟著換
- **日夜變化**：依照現實時間，晚上燈籠會亮
- **離線成長**：作物、工坊、小舖、利息、股市都會在你離開時繼續運作，回來會看到「歡迎回來」總結
- **每日登入禮**（7 天循環）＋ **每日任務**（3 個，每天更新）
- **24 個主線任務**：從新手教學一路到「總資產一百萬的傳說鎮長」
- **24 個成就**、**38 種物品圖鑑**、**10 篇小鎮日記**（隨等級解鎖的文青短文）
- **土地擴建** 12 次、**15 種裝飾**、建築可自由移動

## 🗂 檔案結構

```
slowtown/
├── index.html              遊戲入口
├── manifest.webmanifest    PWA 設定（加到主畫面）
├── sw.js                   Service Worker（離線遊玩）
├── .nojekyll               讓 GitHub Pages 直接提供檔案
├── css/style.css           所有樣式（配色在最上面的 :root）
├── js/data.js              ★ 遊戲資料：作物、配方、建築、居民、股票、任務、日記…
├── js/engine.js            遊戲邏輯：存檔、生產、市場、銀行、股市
├── js/ui.js                介面與操作
└── icons/                  App 圖示
```

## ✏️ 想自己調整？
幾乎所有數值都在 `js/data.js`：
- 想讓作物長快一點 → 改 `CROPS` 裡的 `time`（秒）
- 想新增作物或商品 → 在 `ITEMS` 加一項，再到 `CROPS` 或 `RECIPES` 補上
- 想讓季節變長 → 改 `SEASON_MS`
- 想改配色 → 改 `css/style.css` 最上面的 `:root` 顏色

改完重新上傳到 GitHub，手機重新整理就會更新。若手機一直顯示舊版，可以把 `sw.js` 第一行的 `slowtown-v1` 改成 `slowtown-v2`。
